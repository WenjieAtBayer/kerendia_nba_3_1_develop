## How fast mode works

* **`RUN_CHECKS` switch** at the top of each notebook. `False` (the end-to-end run) skips the 3.0 baseline query, the Step 2 / Step 3 reruns and every all-US comparison. `True` runs everything, as in development.
* **The patient filter runs in Snowflake**, so only the validation patients' rows are pulled:
  * Lab, Dx, Rx: `limit_query_to_test_patients()` (patients with at least one row for a test HCP). This already existed.
  * Px and DM / HF flags have no HCP column. New in `00_cohort_config`: `get_journey_patients(RUN_OUTPUT_DIR)` (patients of the lab / Dx / Rx tables of this run) and `limit_query_to_patients(query, patients)`. Both do nothing in production mode.
* **Run order:** 01 lab, 02 Dx, 03 Rx, then 05 Px and 04 flags (these two read the patients of 01-03), then 06 combine.
